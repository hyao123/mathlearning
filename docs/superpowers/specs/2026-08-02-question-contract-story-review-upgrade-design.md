# 题型契约与故事复盘质量升级设计

## 目标

在不改变五章路线、600 道题、奖励、进度和存档结构的前提下，统一题目为可自动判定的数值题，并让故事引导和战术复盘具备专题差异、难度差异与可校验结构。

## 设计

### 题型契约

- 启用题统一使用 `answerType: "numeric"`。
- `answerFormat` 区分 `integer`、`decimal`、`fraction`、`percent`。
- 题目答案必须包含可解析的数值表达式；颜色、人物、图形、是非、比例字符串和解释句改写为编号、数量、位置或数值题。
- 题目原始数学条件、奖励、关卡顺序和题目 ID 保持不变；必要时只替换题干问法和答案表达。
- 内容校验在构建阶段拒绝非数值答案，界面不再为文本答案生成选择项。

### 故事引导

- 每个专题提供场景、对象、动作和任务阶段四类短文案。
- 文案由专题 ID、题位和难度稳定选择，不使用运行时随机数。
- 每个专题至少提供四种故事变体；故事文本不改变数学条件。
- 题目仍保留原题干字段，故事引导通过 `storyBeat` 单独展示。

### 战术复盘

- 基础题至少包含目标、计算、检查三段信息。
- 进阶题至少包含识别关系、选择方法、计算、检查。
- 提高和 Boss 题增加建模/回代/易错点信息。
- 复盘继续默认折叠，未作答时不可读取答案和解析。
- 校验复盘步骤数、答案一致性、检查字段和易错点字段。

## 兼容性

- 保持现有题目 ID、奖励账本、章节进度、背包键和存档迁移逻辑。
- 只增加题目质量字段和校验，不开放商店、装备或第六章。
- 现有 UI 行为、答错重试、跳过、奖励合并和响应式布局保持不变。

## 验收指标

- 600 道题中非数值答案为 0。
- 五章所有题均有可解析的数值答案格式。
- 每个专题至少 4 个故事变体。
- 复盘步骤符合难度档位，且答案与题目一致。
- `npm test`、严格内容校验、游戏 UI 测试、构建和包体积检查通过。
